# Sakshi Chaudhary — Portfolio

A personal portfolio website built with plain HTML, CSS, and JavaScript — no frameworks, no build step.

🔗 **Live site:** _add your deployed link here_

## Features

- Animated hero section with a canvas-based node-network background
- Scroll-triggered reveal animations
- Hover micro-interactions on project cards, skill chips, and timeline
- Fully responsive (mobile, tablet, desktop)
- Downloadable resume (PDF) linked directly in the nav and hero

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (Canvas API, IntersectionObserver)
- Google Fonts (Space Grotesk, IBM Plex Sans, JetBrains Mono)

## Project Structure

├── index.html  (HTML + CSS + JS all inside)
├── Sakshi_Chaudhary_Resume.pdf 
└── README.md

## How to View

Just double-click `index.html` and it'll open in your browser. No setup, no installation needed.
