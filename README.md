# 🌐 Personal Portfolio Website

A sleek, responsive, and modern personal portfolio website built using core web technologies (**HTML5, CSS3, JavaScript**). This site serves as a digital showcase of my technical skills, personal projects, and background as a developer.

---

## 🚀 Live Demo

🔗 **[View Live Site](https://github.com/)**



---

## ✨ Key Features

* **Fully Responsive:** Seamless layout designed for mobile, tablet, and desktop screens.
* **Interactive UI:** Smooth navigation, dynamic interactions, and subtle animations built with JavaScript.
* **Project Showcase:** Highlights key projects with descriptions, live links, and GitHub repositories.
* **Clean Code Architecture:** Well-structured HTML structure paired with modern, modular CSS and JS.
* **Contact Integration:** Easy access for recruiters and collaborators to get in touch.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup for optimal structure and accessibility.
* **CSS3:** Custom styling, Flexbox/CSS Grid layouts, variables, and responsive media queries.
* **JavaScript (ES6+):** Interactive elements, DOM manipulation, and smooth UI behavior.
